# Judging Criteria (official, from the Luma page)

Five criteria, **20% each**, scored 1 to 5 on paper. Total = sum x 4, out of 100.

| # | Criterion | How we score a 5 |
|---|---|---|
| 1 | **Problem and value** | A real, named user with a real pain. Ideally ourselves (our own product), so the value is not hypothetical |
| 2 | **Execution and quality** | It works live, it looks finished, it is clearly built today |
| 3 | **Use of Manus and tools** | Manus does the orchestration across several surfaces (Apify data in, fal.ai creative, deployed output, connectors). Not one clever prompt |
| 4 | **Potential and impact** | Could go live tomorrow; a repeatable system, not a one-off asset |
| 5 | **Pitch quality** | Before/after felt in the first 15 seconds, live link at the end, clean 2-min and 3-min versions |

## Format
- **Prelim:** 2 min pitch+demo + 1 min Q&A, to ONE judge. Each judge sees 7 to 8 teams, picks **1 finalist + 1 reserve**.
- **Final (top 6):** 3 min + 1 min Q&A, all 6 judges, scores reset, ranking agreed jointly.
