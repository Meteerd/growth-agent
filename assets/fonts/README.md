# Caption fonts (A18)

Free fonts (SIL Open Font License 1.1, from github.com/google/fonts) bundled so captions render the same on every
machine. Variable fonts were instanced to static weights with fontTools. All cover Slovak, Czech and Turkish.

| file | look it stands in for |
|---|---|
| TikTokSans-Black / -Bold | classic TikTok / Reels caption sans |
| Montserrat-Black / -ExtraBold | CapCut / Hormozi bold sans |
| Poppins-ExtraBold | rounded geometric sans |
| Inter-ExtraBold | neutral UI sans (Instagram, LinkedIn) |
| Anton, BebasNeue | condensed all-caps headline |
| DMSerifDisplay, PlayfairDisplay-ExtraBold | serif (editorial, "The cry it out method") |
| Caveat-Bold | handwritten |
